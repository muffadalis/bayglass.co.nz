One-line: The Bayglass pill button — use for every call-to-action; `primary` (navy) for the main action, `accent` (orange) to draw the eye, `secondary`/`outline` for lower emphasis.

```jsx
<Button href="/quote">Get a quote</Button>
<Button variant="accent" size="lg">Book a callout</Button>
<Button variant="outline">Our services</Button>
```

Variants: `primary` (solid navy), `accent` (orange), `secondary` (soft navy tint), `outline` (hairline). Sizes: `sm` / `md` / `lg`. Pass `href` to render an `<a>`.
