# Bayglass website UI kit

The Bay Glass Kerikeri marketing homepage, recreated in the Tailwind "Radiant"
layout language with the Bayglass brand.

- `index.html` — composes the full page. Open this.
- `Hero.jsx` — hero gradient panel (navbar + display heading + CTAs) and supplier strip.
- `Showcase.jsx` — craftsmanship section with a full-bleed project photo.
- `Services.jsx` — three-up services bento grid.
- `DarkSection.jsx` — navy "emergencies / retrofit" section.
- `CtaFooter.jsx` — soft-gradient CTA band + footer.

All sections consume primitives from the `BayglassDesignSystem_405762` bundle
(`Container`, `Navbar`, `Heading`, `Lead`, `Button`, `Gradient`, `BentoCard`,
`Footer`, `Eyebrow`, `LogoCloud`). Imagery is hot-linked from `bayglass.co.nz`.
